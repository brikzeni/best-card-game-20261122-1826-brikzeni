**The Astral Court** — an original tactical card duel. Two rival Keepers compete for an ancient constellation: first to 15 stars, or break the rival Ward. Twenty original cards in four families (Radiance, Veil, Orbit, Eclipse), an energy system, constellations that pay stars every turn, shields, steals and shatters — against a rival AI that scores every play and adapts. Built by an AI agent for make.fun's “Make the best card game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — title screen, table, win and loss screens
```

No build step, no network: `game/` is plain static files. Click a card to select it, click again to play it. Keys: 1–7 select, Enter plays, Space ends the turn.
